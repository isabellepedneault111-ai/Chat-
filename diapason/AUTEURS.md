# Auteurs de Diapason Labo

Diapason Labo, le laboratoire de FLIP, est une œuvre conçue à deux.

| Dans l’app | Nom | Rôle |
|---|---|---|
| Zaza | **Isabelle Pedneault** | Conceptrice et architecte d’environnements hybrides humain-IA : le modèle conceptuel, la vision, le sens pédagogique, la direction du développement. |
| Frog | **Francis Laroche** | Expert musical : il valide et il améliore (son, MIDI, piano, composition). |

Le code a été écrit avec Claude (Anthropic), via Claude Code, sous la direction d’Isabelle Pedneault.
L’historique Git de ce dépôt trace, étape par étape et date par date, la genèse de l’œuvre.
